Questions

Does it work with a barcode scanner?

Yes. Any USB or Bluetooth scanner that types into a field works, focus the search box, scan, and the item opens (or is added to the sale).

Can I use it on my phone?

The whole app is responsive, so it works on a phone or tablet at the counter or in the back store.

Where is my data stored?

In this demo, everything stays in your browser. A production version would sync to a secure cloud database with backups.

Can I import my existing items?

Yes, paste a CSV or upload a file from the Items page. Existing SKUs are updated and new ones are added.
